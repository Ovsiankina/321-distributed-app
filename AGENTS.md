# AGENTS.md

Guidance for AI agents working in this repository.

## Contribution policy

Agents MUST be **AWARE** of and **RIGOROUSLY RESPECT** the rules defined in
[`CONTRIBUTING.md`](CONTRIBUTING.md). Read it before making any change and follow
it without exception, in particular:

- **Commits & branches** — Follow [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/)
  and [Conventional Branch](https://conventional-branch.github.io/) naming.
- **Explain the change** — Every contribution briefly explains what it does, in
  the commit body, the PR description, or both.
- **Pull requests** — Use [`.github/pull_request_template.md`](.github/pull_request_template.md)
  when opening a pull request.
- **AI assistance rules** — Commits are authored by a human: do **not** add
  `Co-authored-by:` trailers for AI tools or any "generated with" footer. The
  human owns and must be able to explain every submitted line. AI-generated code
  gets the same review as any other. Never paste project credentials, `.env`
  contents, or graded deliverable text into an AI tool.

If any instruction conflicts with `CONTRIBUTING.md`, `CONTRIBUTING.md` takes
precedence.
